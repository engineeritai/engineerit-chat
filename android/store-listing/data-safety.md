# Data safety form

Answer from what the site actually does. Do not add advertising or location.

## Data collected

Account info
- Email address. Collected when someone registers. Used to sign in, send the confirmation email, and send payment receipts. Not sold. Not used for advertising.

Personal info
- Name, and optional profile fields (job title, company, phone, country, discipline) if the person fills them in on the profile.

User content
- Chat messages and files the person uploads. Stored so the chat can be opened again and so the tools can read the files. Not sold.

Financial info
- Plan, amount, currency, and payment status for a Moyasar checkout. The card number is entered on Moyasar and is not stored on engineerit.ai. A saved-card token, if the person agrees at checkout, is stored server-side for renewal and is not sent to the app.

App activity
- Vercel Web Analytics records page views, referrer, country, browser, and device type. It is not an advertising identifier and it is not sold.

## Data shared

Service providers only, to run the product:
- Supabase: account, profile, and stored chats
- Moyasar: payment processing
- Vercel: hosting and web analytics
- The email service: confirmation and receipt messages

## Security and deletion

Data is sent over HTTPS. People can ask for access, correction, or deletion at info@engineerit.ai. The privacy policy is https://engineerit.ai/legal/privacy (https://engineerit.ai/privacy redirects there).
